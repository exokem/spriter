## `scan`

Scans the site and indexes information about what is available.

### `scan consoles`
Updates the console cache.

### `scan games --meta` `scan -m`
Scans game metadata (page and game count).

### `scan games --all` `scan -a`
Scans all game pages. (may take >10 minutes)

### `scan games --page <page-number>`
Scans a specific game page.

### `scan games --pages <first-page-number> <last-page-number>`
Scans a specific range of game pages. Bounds are inclusive
